# Deployment Overview

Stitchd Feature Flag is designed for self-hosted deployment. This guide covers all infrastructure prerequisites and configuration.

## Prerequisites

- PostgreSQL 16+
- ClickHouse 24+
- Rust toolchain (for building from source)
